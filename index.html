This warehouse is the experiment harness and provenance gate for cost-aware routing. It writes cells, schema checks, and a routing verdict file. A closed provenance gate does not mean the router won.

The object

Drivers emit per-mix cells under a fixed schema: arm choice, cost fields, damage fields, and stream labels.

The provenance gate checks that those fields are present, typed, and in-scope. The verdict file then scores the routing rule against the frozen majority gate.

What is measured

  • Provenance gate: 99/99 in-scope cells (integrity only)
  • Routing verdict: edit-majority 0.103 vs the 0.5 majority gate
  • Per-arm serve times on the recorded mix: edit 0.020 s, retrieval 0.120 s

Protocol

  • Run cell drivers from the harness root with the frozen mix list.
  • Run the provenance gate on the cell directory.
  • Read the verdict file for the routing outcome. Do not invert integrity into a routing win.

Measurements

Contract

Cells + provenance report + verdict file. A KILL on the routing gate is a valid contract output.

Non-goal

This site does not claim a working router. It documents how the routing numbers were produced.
